# مدرسة غزة الصغيرة – Little Gaza School

تطبيق أندرويد مجاني يعمل بالكامل بدون إنترنت، يساعد أطفال غزة على تعويض ما فاتهم في العربية والرياضيات حسب مستواهم الحقيقي.

- اختبار تحديد مستوى لكل مادة
- 76 درساً (عربي: الحروف، الحركات، الكلمات — رياضيات: الأعداد، الأشكال، الجمع والطرح)
- ركن الهدوء: تنفّس، مشاعر، قصص قصيرة
- حتى 5 أطفال على نفس الهاتف، ووضع للأهل والمعلمين برقم سري
- لا يجمع أي بيانات، ولا يحتاج إذن الإنترنت، وبدون إعلانات
- زر لمشاركة التطبيق نفسه مع هاتف آخر

## البناء
GitHub Actions يبني نسخة debug تلقائياً. لنسخة جوجل بلاي الموقّعة أضف هذه الأسرار للمستودع:
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

## المحتوى
كل الدروس في `app/src/main/assets/content.json`. لإضافة دروس يكفي تعديل هذا الملف.
